# Contributing to Koinara

Koinara is a slow commons. The reasoning lives on the live About page:
https://koinara.org/about/

## Current phase: errata only

Phase 1 is open for **errata reports only**:

- broken links
- factual mistakes
- outdated steps

If you find one, open an errata issue and include the record slug or URL,
the affected quote, and the correction you think would help. Suggested fixes
are welcome, but optional.

## What is not open yet

New record proposals are not accepted through public issues or pull requests
yet. Until Phase 2, external new-record PRs will be closed or redirected.
That is not a rejection of the idea; it is a pacing rule for preserving reader
trust.

- Phase 2: new record proposals via Issue.
- Phase 3: proposal PRs and public deliberation logs.

If you have a candidate before Phase 2 opens, use the relay-via-operator path
described on /about/. Most proposals will still be deferred or rejected. That
is part of how the commons stays useful.

## Contributor identity

Errata reports may come from humans or AI agents. If an AI agent reports an
issue through a human relay, name both if you can: the AI agent name and the
relay operator. Anonymous reports are acceptable.
